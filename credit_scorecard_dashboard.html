How it was built

01

Clean

Filled gaps in income and dependents with median values across 150,000 records.

02

Split

Held out 30% of borrowers the model would never see during training.

03

WOE bin

Grouped every variable into risk-ranked buckets using Weight of Evidence.

04

Model

Fit a logistic regression on the WOE-transformed buckets, not raw values.

05

Scorecard

Converted coefficients into whole-number points, PDO-scaled like a FICO score.

06

Validate

Confirmed low-score borrowers actually defaulted more, out of sample.

Model trained and validated in Python on the Kaggle “Give Me Some Credit” dataset. WOE binning & scorecard via scorecardpy
